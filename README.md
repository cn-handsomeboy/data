# 🌱 蔗循智策

## 面向中国-东盟的甘蔗副产物循环经济跨境数据协同决策系统

> **2026年「数据要素×」大赛广西分赛 · 高校赛道 · 现代农业组**
>
> **学术对标**：石杰锋等 (2023) 《智慧农业(中英文)》 | **国标对标**：GB/T 47950-2026, GB/T 46353-2025

---

## 📌 30秒速览

**问题**：广西年产蔗叶数百万吨，15%仍被焚烧；蔗渣价值被严重低估（造纸浆 vs 锅炉燃料差7倍）；糖企缺乏数据驱动的副产物决策工具。

**方案**：构建「数据层→模型层→应用层→产品层」四层决策系统，融合**7类异构数据**（政府开放+国际标准+市场+文献），用**GBRT + LOOCV**预测产量（R²=0.893）、**IPCC AR6 Tier 1**核算碳排放、**五方案多目标优化**（收益vs碳减排权重可调）推荐最优副产物利用方案，支持**中国-泰国-越南-缅甸-老挝五国跨境对比**，配套**数据产品三证一价**与**用户验证闭环**。

**效果**：以崇左市10亩蔗田为例，最优循环方案**净收益15,886元**（比传统焚烧模式增收520%），**碳减排19.3吨CO₂e**，综合收益（含碳交易）达**17,527元**。

**数据基准**：2025/2026榨季广西甘蔗种植面积1,234万亩，甘蔗收购价540元/吨，蔗农收入328亿元（同比+20%）。2026年7月22日全国碳市场CEA收盘价91.03元/吨。

## 📊 技术架构

```
数据层（7类异构，数据质量A/B/C三级分级）
  ├─ 广西甘蔗产量 (统计年鉴 2015-2024, 7市×10年=70样本)
  ├─ 气象数据 (tianqi24.com + Open-Meteo ERA5, 7市×10年逐月=840行)
  ├─ 东盟四国气象 (Open-Meteo ERA5, 泰/越/缅/老各2主产蔗区, 2010-2024逐日=43832行)
  ├─ 跨境产量-气象数据集 (FAO产量×东盟真实气象, 4国×10年=40真实数据点)
  ├─ FAO全球数据 (中/泰/越/缅/老五国, 2015-2024, A/B/C三级数据质量分级)
  ├─ IPCC排放因子 (AR6 GWP, 23条均有溯源)
  ├─ 碳交易价格 (上海环交所, 月度, 2021-07至2026-07)
  ├─ 副产物参数 (文献综述, Andreae 2001等)
  └─ 市场价格 (新华财经/1688/行业研报/汇率换算)
        ↓
模型层（5个模块联动）
  ├─ YieldPredictor: Ridge/RF/GBRT/ElasticNet, LOOCV, 生长季特征+城市哑变量+交互
  ├─ ByproductEstimator: 标准系数法(蔗叶0.18/蔗渣0.24/滤泥0.04/糖蜜0.035)
  ├─ CarbonCalculator: IPCC AR6 Tier1, N₂O 44/28转换, 全链条(种植+机械+电力)
  ├─ EconomicCalculator: 多路径对比(蔗渣造纸浆/板材/沼气/锅炉/环保餐具)
  └─ OptimizationEngine: 五方案差异化碳排放 + 双目标Min-max标准化(收益/碳减排权重可调)
        ↓
应用层 (Streamlit)
  ├─ 交互式参数设置 + 模型质量仪表盘 + 模型对比 + SHAP可解释性
  ├─ 五方案对比(传统/改良传统/基础循环/进阶循环/最优循环) + 权重滑块实时调节
  ├─ 碳排放结构 + 碳价敏感性分析 + 碳交易情景切换(当前/未来)
  ├─ 一键加载示范场景(来宾/崇左/南宁预置参数)
  ├─ 数据要素闭环(三证一价 + 数据血缘Sankey + 交易模拟)
  ├─ 用户验证闭环(三类用户案例 + 满意度对比)
  ├─ CCER碳汇方法学框架 + 空间可视化(广西7市+东盟4国)
  ├─ 跨境对比（中-泰-越-缅-老）+ 数据质量分级 + 框架可移植
  └─ Agent智能问答（自然语言→决策结果）
        ↓
数据产品层
  ├─ CSV决策报告 (参数+结果, UTF-8)
  ├─ JSON数据产品 (结构化, 含API Key鉴权)
  ├─ 三证一价证书体系(登记/质量/安全/定价)
  └─ 对齐 GB/T 47950-2026 / GB/T 46353-2025 / GB/T 36344-2018
```

## 📈 关键指标

| 指标 | 数值 | 说明 |
|------|------|------|
| 训练样本 | 70 (7市×10年) | 城市-年份细粒度 + 生长季气象聚合 |
| 最优模型 | GBRT LOOCV | GBRT R²=0.893 (learning_rate=0.05, max_depth=4) |
| **R² (LOOCV)** | **0.893** | 学术对标：石杰锋2023单蔗区LSTM R²=0.849 |
| R² (RepeatedKFold) | 0.842 ± 0.072 | 5×10-fold 稳健估计 |
| RMSE | 0.299 吨/亩 | 误差约5.4%，满足田间决策 |
| Stacking Ensemble | R²=0.806 | Ridge+RF+GBRT→Ridge meta-learner |
| 蔗渣价值提升 | 30倍 | 锅炉50→环保餐具1,500元/吨（来宾真实数据） |
| 最优增收 | 520% | 传统2,563→最优15,886元/10亩 |

### 学术R²对标（与已发表文献对比）

| 文献 | 数据规模 | 方法 | R² | 预测目标 |
|------|:---:|------|:---:|:---|
| 石杰锋等 (2023) 《智慧农业》 | 5市×18年 | BPNN + 敏感时段 | 0.965 | 气象产量残差 |
| 石杰锋等 (2023) | 同上 | LSTM 单蔗区 | 0.849 | 气象产量残差 |
| Medar et al. (2021) | 印度蔗区 | ML Ensemble | 0.78 | 实际产量 |
| Bocca & Rodrigues (2016) | 巴西蔗区 | RF | 0.75 | 实际产量 |
| **本项目** | **7市×10年** | **GBRT + LOOCV** | **0.893** | **实际产量** |

> **注**：石杰锋等的高R²源于预测HP滤波分离后的气象产量残差（难度较低），本项目直接预测实际产量（难度较高），不可直接比较数字大小。本项目R²=0.893在直接预测实际产量场景下处于国内领先水平。数据来源：31个真实产量锚点（广西统计年鉴+各市统计公报+聚汇数据），缺失年份采用趋势内插。

## 🔒 数据合规与安全

### 数据来源（全部公开合法）
| 来源 | 数据集 | 合规依据 |
|------|------|----------|
| 广西统计局 | 甘蔗产量 | 《政府信息公开条例》 |
| tianqi24.com / Open-Meteo | 气象数据（含东盟四国） | 公开天气数据 / ERA5开放数据 |
| FAO | 全球甘蔗数据 | FAO开放数据政策 |
| IPCC | 排放因子 | IPCC数据政策 |
| 上海环交所 | 碳交易价格 | 《碳排放权交易管理办法》 |
| Google Scholar | 副产物参数 | 学术引用规范 |
| 新华财经/1688 | 市场价格 | 公开商业信息 |

> **跨境数据真实性说明**：东盟四国产量来自 FAO 统计局开放数据（4国×10年，A/B 数据质量）；
> 配套的东盟气象为 Open-Meteo ERA5 再分析（与广西同源、可溯源），二者联结为
> `asean_yield_weather.csv`（40 个真实国家-年级产量+气象数据点），已登记进
> `data/.file_hashes.json` 校验指纹；跨境对比即基于各国真实生长季气候，而非复用中国天气。

### 安全措施
- **API Key 鉴权**：FastAPI Security + X-API-Key 验证
- **全公开数据**：不涉及个人隐私、商业秘密、国家秘密
- **分类分级**：A/B/C三级数据质量分级
- **不存储用户输入**：查询参数仅内存计算，不落盘
- **跨境合规**：五国数据均为FAO公开数据+政府公开发布值
- **数据产品标准化**：CSV+JSON格式，对齐GB/T 47950-2026
- **全文见** `DATA_SECURITY.md` 和 `数据安全与分级保护方案.md`
